🚀 高性能路由

支持洋葱模型中间件，提供日志、认证、CORS 等常用中间件

🛡️ 安全防护

内置路径遍历攻击防护、点文件访问控制、请求验证等安全特性

📊 性能监控

💻 代码示例

// 基本路由设置 mut app := hono.Hono.new() // 静态文件服务 app.use(hono.serve_static_default()) app.use(hono.serve_static_path('/assets', './static')) // 基础路由 app.get('/hello', fn (mut c hono.Context) http.Response { return c.text('Hello, World!') }) // 动态路由 app.get('/users/:id', fn (mut c hono.Context) http.Response { user_id := c.params['id'] return c.json('{"user_id": "${user_id}"}') }) // 文件服务 app.get('/file/:filename', fn (mut c hono.Context) http.Response { filename := c.params['filename'] return c.file('public/${filename}') }) // 启动服务器 app.listen(':8080')
